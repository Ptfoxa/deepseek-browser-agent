单元测试覆盖：

- 操作协议严格 Schema、额外字段拒绝、操作数量上限；
- 高风险文字/表单按钮/链接分类；
- 计划哈希、单次授权、过期和页面指纹绑定；
- 敏感字段过滤、链接查询参数移除、正文 PII 脱敏、文本截断；
- 执行器逐项校验、目标类型不匹配、页面变化、点击阻止和撤销冲突；
- DeepSeek 客户端成功响应、无效 Key、429 重试、超时和用户取消。

集成测试覆盖：

- 未配置 Key 时拒绝请求；
- 保存设置后不向 UI 状态暴露 Key；
- 分析页面 → 生成计划 → 未批准不执行 → 批准执行 → 撤销；
- 模型输出含额外 `selector` 字段时拒绝；
- 高风险点击被阻止；
- 页面跳转和执行时 stale 检查；
- 拒绝计划不执行；
- 自定义 API origin 缺少权限时拒绝保存。

浏览器端到端测试：

1. 通过 CDP `Extensions.loadUnpacked` 加载生产构建，侧边栏页面渲染。
2. 真实 Chrome 消息通信读取本地 fixture 页面，密码和邮箱值不出现在快照中。
3. 保存/删除 API Key，UI 状态不包含 Key。
4. 本地模拟 DeepSeek API：分析 → 生成计划 → 批准 → 实际修改 `<h1>` → 撤销恢复。
5. `chrome://` 内部页面返回 `unsupported_page`，不注入脚本。
